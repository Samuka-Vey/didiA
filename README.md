## DiDiA
### Projeto de ``assistente virtual``

 O que é o DiDiA 
----
<p>O DDA funcionará como assistente, garantindo automação de tarefas simples, como comandos desde abrir navegador, fechar dispositivo eletrônico e tocar alguma música.</p>

```text
DiDiA/
├── app.py                 # Arquivo principal
├── system_commands.py      # Módulo 1: Comandos do sistema
├── voice_handler.py        # Módulo 2: Voz (entrada/saída)
├── assistant_bot.py        # Módulo 3: Bot coordenador
├── facial_expressions.py   # Módulo 4: Expressões (próximo)
└── ai_integration.py       # Módulo 5: IA (por último)
```
